# Kịch bản demo

1. Chạy `docker-compose up --build`.
2. Mở `http://localhost:5173`.
3. Đăng ký tài khoản A.
4. Mở trình duyệt ẩn danh, đăng ký tài khoản B.
5. A tìm B bằng email.
6. A gửi lời mời kết bạn.
7. B vào mục lời mời, bấm chấp nhận.
8. A mở cuộc trò chuyện với B.
9. A gửi tin nhắn, B nhận realtime.
10. B gửi lại tin nhắn.
11. A reload trang để chứng minh lịch sử tin nhắn được lưu.
12. A tạo nhóm, thêm B vào nhóm.
13. A và B chat nhóm realtime.
14. Gửi ảnh và file.
15. Demo typing status.
16. Demo online/offline bằng cách đóng tab B.
